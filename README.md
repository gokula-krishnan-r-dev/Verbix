# EveryChat - AI Assistant for macOS

EveryChat is a powerful AI assistant that integrates seamlessly with macOS, allowing you to generate AI responses based on selected text from any application.

## Features

- **Global Text Selection Detection**: Select text in any application and press Option+Space to invoke the AI assistant
- **Floating AI Assistant Panel**: Clean, non-intrusive popup with the selected text and AI-generated responses
- **Multiple Response Styles**: Choose between concise, balanced, detailed, professional, or casual response styles
- **Edit Before Sending**: Review and edit AI-generated responses before inserting them
- **Keyboard Shortcuts**:
  - Option+Space: Open assistant with selected text
  - Enter: Insert response
  - Esc: Dismiss panel
- **History Management**: Save previous interactions for easy reference
- **Secure API Key Storage**: OpenAI API keys are securely stored in the macOS Keychain

## Requirements

- macOS 12.0 or later
- OpenAI API key (get one at [platform.openai.com](https://platform.openai.com))

## Installation

1. Download the latest release from the [Releases](https://github.com/yourusername/everychat/releases) page
2. Move EveryChat to your Applications folder
3. Launch the application
4. Follow the onboarding process to set up your API key

## First-time Setup

On first launch, EveryChat will:
1. Guide you through an onboarding process
2. Ask for accessibility permissions (required to detect selected text)
3. Prompt you to enter your OpenAI API key

## How to Use

1. Select text in any application
2. Press Option+Space to open the EveryChat assistant
3. Choose your preferred response style
4. The AI will generate a response based on the selected text
5. Edit the response if needed
6. Click "Insert" to paste the response back to the original application

## Privacy & Security

- Your OpenAI API key is stored securely in the macOS Keychain
- All AI processing happens through the OpenAI API
- No data is stored on our servers
- Your chat history is stored locally on your device
- You can clear your chat history at any time in Settings
